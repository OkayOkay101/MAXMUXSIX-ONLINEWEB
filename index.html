📖 คลิกเพื่อดูวิธีรับ Web App URL จาก Google ใน 2 นาที
1. เข้าเว็บ script.google.com แล้วกดปุ่ม "+ โครงการใหม่" (New project)
2. ลบโค้ดเดิมออกทั้งหมด แล้วกดปุ่ม ไปวางแทนที่ (หรือดูในไฟล์ google_apps_script.js)
3. กด บันทึก (Ctrl + S)
4. กดปุ่มสีน้ำเงิน "ทำให้ใช้งานได้" (Deploy) > "การทำให้ใช้งานได้ใหม่" (New deployment)
5. เลือกประเภทเป็น "เว็บแอป" (Web app) โดยตั้งค่า:
    • ดำเนินการในฐานะ: ฉัน (อีเมลของคุณ)
    • ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone) *(สำคัญมาก!)*
6. กด Deploy > ให้สิทธิ์บัญชี Gmail > คัดลอก Web app URL ที่ได้มาวางในช่องด้านบนนี้ได้เลย!
