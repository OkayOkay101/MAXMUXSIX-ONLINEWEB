# MAXMUXSIX — สมาชิกกลาง

ผู้ใช้อนุมัติให้ลงมือวันที่ 12 ตุลาคม 2026 สมัครด้วยอีเมลและรหัสผ่านแล้วเข้าได้ทุกเครื่อง ไม่ใช่การเชื่อมบัญชีเว็บอื่น ไม่มีโปรเจกต์ Supabase ในขณะพัฒนา

## ขอบเขตและเงื่อนไขรับงาน

- Supabase Auth เก็บ credentials; profiles เก็บชื่อ โทรศัพท์ ที่อยู่ และรหัสแนะนำเพื่อน เปิด RLS อ่านได้เฉพาะเจ้าของ
- ไม่ยอมรับบัญชีหรือสถานะผู้ดูแลจาก localStorage/sessionStorage เดิม ไม่มี fallback ไปใช้รหัสผ่านเก่า
- สมัครพร้อมยอมรับเงื่อนไข ยืนยันอีเมล เข้าสู่ระบบ ออกจากระบบ ลืม/ตั้งรหัสผ่าน รองรับคำเชิญ
- ผู้ดูแลอ่านรายการแบบแบ่งหน้า เชิญเพิ่มผู้ใช้ และลบผู้ใช้ โดย Edge Function ตรวจ JWT กับ Auth และตารางสิทธิ์ส่วนตัวทุกครั้ง ห้ามลบตนเองหรือผู้ดูแลคนอื่น
- Publishable key เท่านั้นในเว็บ service-role อยู่ใน Supabase environment เท่านั้น ไม่เพิ่ม secret ลง repo
- ข้อมูลสินค้า ตะกร้า คำสั่งซื้อและกล่องอีเมลจำลองยังเป็นข้อมูลในเครื่อง ไม่ย้ายโดยปริยาย
- หากยังไม่ได้ตั้งค่า ปิดการสมัคร/เข้าสู่ระบบด้วยข้อความชัดเจน ร้านและตะกร้ายังใช้งานได้
- บัญชี local เดิมไม่ถูกอัปโหลดหรือให้สิทธิ์อัตโนมัติ เจ้าของต้องสมัคร/ยืนยันใหม่
- การลบ Auth ไม่รับประกันยกเลิก JWT ที่ออกแล้วทันที ตารางส่วนกลางใช้ profile/role ที่ยังมีอยู่เป็นหลักฐานสิทธิ์

## UI

ใช้ฟอร์มและ modal เดิม โทน organic/natural เขียวเข้มและส้มไฟแบบ MAXMUXSIX ฟอนต์เดิม ใช้ CSS variables ระยะ 8/16/24px ไม่มีเอฟเฟกต์เพิ่ม มีสถานะกำลังทำงาน สำเร็จ/ผิดพลาด focus และแป้น Escape กลับปุ่มเดิม ผู้ดูแลเห็นปุ่มจัดการสมาชิก desktop/mobile หลัง server ยืนยันสิทธิ์เท่านั้น

## ขอบเขตการพิสูจน์

Node unit tests + PostgreSQL-compatible PGlite สำหรับ migration/RLS + browser checks ด้วย provider จำลอง ไม่ใช่หลักฐานอีเมลจริงหรือทดสอบข้ามเครื่องบน Supabase ที่ยังไม่มี ต้องตั้งค่าโปรเจกต์/SMTP/deploy function และทดสอบจริงก่อนใช้งานกับลูกค้า
