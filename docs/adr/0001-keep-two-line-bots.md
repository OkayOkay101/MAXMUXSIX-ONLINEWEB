# 0001: เก็บ LINE bot สองไฟล์ และยึดโค้ดเว็บจริงเป็นฐาน

วันที่: 2026-11-26

## บริบท
โค้ดสอง repo ไม่มีประวัติ Git ร่วมกัน เว็บจริงใหม่กว่า ส่วน PR #3 ของ repo เก่ามีการเสริมความปลอดภัยที่เว็บจริงยังไม่มี

## การตัดสินใจ
- ยึดโค้ดเว็บจริง (`a01a9fb`) แล้วเติมการป้องกันจาก PR #3 ทีละจุด
- `line_bot_smart_apps_script.js` (ค่าหลัก และเป็นตัวที่ติดตั้งอยู่): ตอบคำถาม มีปุ่ม quick reply และพาสั่งซื้อ มาจาก repo เก่า ปรับข้อมูลรับเงินเป็นข้อความเดโม และแก้การจดข้อความกับการแจ้งผลบันทึก
- `line_bot_apps_script.js` (ทางเลือก): จดข้อความแล้วตอบรับ
- แก้ 2026-11-26: เดิมตัวจดข้อความเป็นค่าหลัก เปลี่ยนเพราะผู้ใช้ต้องการปุ่มเมนู rich menu ของ LINE OA ส่งข้อความ `เมนู`, `สั่งซื้อ`, `โปรโมชั่น`, `ค่าจัดส่ง`, `หน้าร้าน`, `ติดต่อแอดมิน` ให้บอตตัวนี้ ถ้าเปลี่ยนคำที่บอตรับ ต้องแก้เมนูด้วย
- ติดตั้งได้ครั้งละหนึ่งไฟล์ในโปรเจกต์ Apps Script

## ผลที่ตามมา
- แก้เรื่องความปลอดภัยของ LINE ต้องแก้ทั้งสองไฟล์ (`tests/unit/50-combined-bots.test.js` ตรวจบางส่วนทั้งคู่)
- bot ค่าหลักเก็บชื่อ เบอร์โทร และที่อยู่ที่ผู้ใช้พิมพ์ลง Sheet จึงต้องใช้กับข้อมูลสมมติ
- bot ค่าหลักตรวจรูปแบบคำตอบทุกขั้น และขั้นที่ค้างหมดอายุใน 30 นาที (ดู `docs/superpowers/specs/2026-11-26-smart-bot-order-flow-design.md`)
