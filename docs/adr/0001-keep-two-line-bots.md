# 0001: เก็บ LINE bot สองไฟล์ และยึดโค้ดเว็บจริงเป็นฐาน

วันที่: 2026-11-26

## บริบท
โค้ดสอง repo ไม่มีประวัติ Git ร่วมกัน เว็บจริงใหม่กว่า ส่วน PR #3 ของ repo เก่ามีการเสริมความปลอดภัยที่เว็บจริงยังไม่มี

## การตัดสินใจ
- ยึดโค้ดเว็บจริง (`a01a9fb`) แล้วเติมการป้องกันจาก PR #3 ทีละจุด
- `line_bot_apps_script.js` (ค่าหลัก): จดข้อความแล้วตอบรับ
- `line_bot_smart_apps_script.js` (ทางเลือก): ตอบคำถามและพาสั่งซื้อ มาจาก repo เก่า ปรับข้อมูลรับเงินเป็นข้อความเดโม และแก้การจดข้อความกับการแจ้งผลบันทึก
- ติดตั้งได้ครั้งละหนึ่งไฟล์ในโปรเจกต์ Apps Script

## ผลที่ตามมา
- แก้เรื่องความปลอดภัยของ LINE ต้องแก้ทั้งสองไฟล์ (`tests/unit/50-combined-bots.test.js` ตรวจบางส่วนทั้งคู่)
- bot ทางเลือกเก็บชื่อ เบอร์โทร และที่อยู่ที่ผู้ใช้พิมพ์ลง Sheet จึงต้องใช้กับข้อมูลสมมติ
- bot ทางเลือกตรวจรูปแบบคำตอบทุกขั้น และขั้นที่ค้างหมดอายุใน 30 นาที (ดู `docs/superpowers/specs/2026-11-26-smart-bot-order-flow-design.md`)
