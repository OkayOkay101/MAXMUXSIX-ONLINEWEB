# MAXMUXSIX ร้านออนไลน์

เว็บสาธิตของ MAXMUXSIX ร้านข้าวหลามเผาเตาถ่าน หนองมน ชลบุรี เว็บนี้ไม่ได้ขาย จัดส่ง หรือรับชำระเงิน

[English](README.md) · [คู่มือใช้งาน](docs/user-guide_TH.md) · [การตั้งค่า](docs/configuration_TH.md) · [การพัฒนา](docs/development_TH.md)

![หน้าร้าน MAXMUXSIX](store_front.jpg)

## ความต้องการ

- Node.js 22 ขึ้นไป (สำหรับการทดสอบและ build) และ Python 3 (สำหรับเปิดไฟล์)
- Google Chrome ใช้เฉพาะการทดสอบ browser

## การติดตั้ง

```bash
npm ci --ignore-scripts
python -m http.server 8000
```

จากนั้นเปิด http://localhost:8000/ ในเบราว์เซอร์ อย่าเปิด `index.html` จากดิสก์ เพราะลิงก์ในอีเมลของระบบสมาชิกต้องใช้ HTTP(S)

## คุณสมบัติ

- **ร้านค้า:** ค้นหาและกรองสินค้า ตะกร้าที่ใช้โค้ดส่วนลดได้ และแบบทดสอบเลือกรสชาติ
- **สมาชิก:** สมัคร ยืนยันอีเมล เข้าสู่ระบบ และรีเซ็ตรหัสผ่านผ่าน Supabase Auth
- **อีเมลและแชต:** อีเมลยืนยันคำสั่งซื้อและ LINE bot ทำงานผ่าน Google Apps Script ทั้งคู่

## การใช้งาน

| งาน | ที่อยู่ในหน้าเว็บ |
|---|---|
| ค้นหาสินค้า | ช่องค้นหาและตัวกรองที่หน้าแรก |
| ใส่ตะกร้า | "🛒 เพิ่มลงตะกร้า" บนการ์ดสินค้า |
| ใช้โค้ดส่วนลด | ช่องโค้ดส่วนลดในตะกร้า (`MAX10` ต้องซื้อขั้นต่ำ 150 บาท) |
| เข้าสู่ระบบ | ส่วนสมาชิก ปุ่ม "เข้าสู่ระบบ" |

## การตั้งค่า

การตั้งค่าที่เปิดเผยได้อยู่ในไฟล์ `auth-config.js` ดูรายการทั้งหมดใน [docs/configuration_TH.md](docs/configuration_TH.md) ห้ามใส่ `service_role` หรือ `sb_secret` ในไฟล์ใดของ repo นี้

## การทดสอบ

```bash
npm test
```

## โครงสร้างโปรเจกต์

- `index.html` (หน้าร้าน) และ `auth-config.js` (ค่า Supabase ที่เปิดเผยได้)
- `assets/`, `scripts/`: ไฟล์ JavaScript, ไลบรารีที่รวมไว้, รูปภาพ และสคริปต์ช่วย build
- `supabase/`, `tests/`: migration, Edge Functions และการทดสอบ
- `docs/`: คู่มือใช้งาน การตั้งค่า การพัฒนา และบันทึกการตั้งค่า
- `*_apps_script.js`: ไฟล์ Google Apps Script (ติดตั้ง LINE bot เพียงไฟล์เดียวต่อหนึ่งโปรเจกต์)

## สัญญาอนุญาต

`package.json` ระบุสัญญาอนุญาตเป็น `UNLICENSED` ซึ่งไม่ได้อนุญาตให้ใช้แบบโอเพนซอร์ส
